# 项目剪辑配置

> 版本：1.0  
> 适用范围：本项目的 ChatCut、HyperFrames、字幕、配音与广告视频任务

## 1. 基本原则

1. 每次剪辑前先读取本文件。
2. 当前任务中的明确要求优先于本文件。
3. ChatCut 负责可编辑主时间线；HyperFrames 负责钩子、卖点、价格与 CTA 动效。
4. 不使用单个扁平成片替代原始时间线。
5. 默认使用“同源连续块”：一个源素材的多个可用片段尽量连续使用。

## 2. 默认规格

- 平台：Meta/Facebook，可按任务改为 TikTok 或其他平台
- 画幅：9:16，1080×1920
- 帧率：30 fps
- 时长：20–30 秒
- 语言：日语
- 配音：清晰、利落、有亲和力的女声；ElevenLabs 可用时优先
- 素材原声：静音，旁白为主
- 音频：-14 至 -12 LUFS，真峰值不高于 -1 dBTP

## 3. 默认叙事结构

`钩子 → 产品清晰度 → 细节 → 视觉证明 → 使用场景 → 优惠 → CTA`

| 模块 | 推荐时段 |
| --- | --- |
| 钩子 | 0–3 秒 |
| 产品与细节 | 3–10 秒 |
| 上身/效果证明 | 10–18 秒 |
| 场景/搭配 | 18–25 秒 |
| 优惠与 CTA | 最后 2–4 秒 |

## 4. 素材与节奏

- 每条 20–30 秒成片优先使用 6–12 个强片段。
- 一个源素材优先连续使用 2–5 个不同视觉状态。
- 单个视觉状态默认 1.2–2.2 秒；动作未表达完整时不要提前切走。
- 只在故事边界切换人物、场景或来源。
- 禁止默认使用 `A → B → A → C → A` 的往返排列。
- 前 3 秒至少出现两个连贯视觉状态，并立即看清产品或穿着结果。

## 5. 文案与证据

- 版型、比例和穿搭文案对应全身、正侧背或走动镜头。
- 面料、纽扣、领口和做工文案对应近景。
- 舒适、垂感和遮盖效果仅在画面能直接证明时使用。
- 价格、折扣、库存、试用期和保证必须来自用户确认或当前落地页。
- 不使用未经证实的数字显瘦、身体羞辱、夸张前后对比或虚假稀缺。

## 6. 字幕与动效

- 日文字幕默认使用粗体白字、黑色描边或阴影。
- 每屏 1–2 行，每行约 10–18 个日文字符。
- 核心词使用黄色或橙色，普通说明保持白色。
- 底部保留至少 15% 平台安全区。
- HyperFrames 入场 0.2–0.4 秒，重要文字停留至少 1.2 秒。
- 不使用持续漂浮、无意义旋转或遮挡商品的动效。

## 7. 轨道分工

- `V1`：原始视频素材
- `V2/V3`：HyperFrames 透明动效或 ChatCut 原生 MG
- `A1`：最终旁白
- `A2`：BGM
- `Captions`：从最终旁白生成的独立字幕

## 8. 完成检查

- [ ] 第一帧能看清产品或穿着结果。
- [ ] 同源素材已尽量连续组合。
- [ ] 每句卖点都有对应视觉证据。
- [ ] 旁白完整，没有裁断句子。
- [ ] 字幕与动效不遮挡脸部和商品细节。
- [ ] 旧 CTA 已移除，没有双重价格卡。
- [ ] 价格与优惠信息已核实。
- [ ] 最终 CTA 停留至少 1.5 秒。
- [ ] 所有主要轨道保持独立可编辑。

## 9. 配置变更

只有在用户明确要求“以后都这样剪”或“更新默认配置”时，才修改本文件并更新版本。
